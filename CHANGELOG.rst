=========
Changelog
=========

0.0.1
=====

* Initial public release of ``nexussim-server``.
* OpenAPI-generated Flask service for the MIRTO DynAA simulation API.
* Includes the base server scaffold, example simulation payloads, and test
  entry points.
* Submodules  for ``cDynAA`` and ``nexussim`` are included as git submodules, pointing to the public GitHub repositories.
